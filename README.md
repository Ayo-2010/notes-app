# Notely

A notes app with a searchable sidebar.

## Features

- Create, edit and delete notes
- Live search across titles and bodies
- Auto-save as you type
- Dark mode and a mobile drawer layout

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
